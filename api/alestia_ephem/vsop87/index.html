Module vsop87 

Source
Expand description

VSOP87 analytical planetary ephemerides.

The series are Celestia’s truncated VSOP87B (heliocentric spherical variables, planets) and VSOP87E (barycentric rectangular variables, Sun) tables. They are compiled in from data/vsop87.bin, which is generated from the upstream tables by data/gen_vsop87.py.

Reference: Bretagnon P., Francou G., Astron. Astrophys. 202, 309 (1988).
