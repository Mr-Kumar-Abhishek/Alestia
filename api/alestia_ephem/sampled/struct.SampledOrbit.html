Struct SampledOrbit

pub struct SampledOrbit { /* private fields */ }

Unevenly spaced position-only trajectory (.xyz) with linear or Catmull-Rom cubic interpolation.

Source

pub fn from_xyz_str( input: &str, interpolation: TrajectoryInterpolation, ) -> Result<Self, SampleError>

Parse an ASCII .xyz trajectory (tdb x y z with optional # comments).

Coordinates in the file are transformed from standard (x, y, z) to Celestia (x, z, -y) coordinates, matching upstream LoadSamplesXYZAscii.

§Errors

Returns SampleError::MalformedToken for non-numeric/non-finite fields or incomplete trailing records, or SampleError::EmptySamples if no monotonic sample exists.

Source

pub fn from_samples( samples: &[XyzSample], interpolation: TrajectoryInterpolation, ) -> Result<Self, SampleError>

Construct a SampledOrbit directly from XyzSample records already in Celestia coords.

Out-of-order or duplicate timestamps are skipped to match upstream LoadSamples.

§Errors

Returns SampleError::EmptySamples if no monotonic sample exists.
