Source
Expand description

Sampled ASCII (.xyz, .xyzv, .q) and binary (CELXYZV\0 .xyzvbin) trajectories and attitude keyframes matching celephem/samporbit.cpp, samporient.cpp, sampfile.h, and xyzvbinary.h (FR-013).
